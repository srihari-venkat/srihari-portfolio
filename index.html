QuickMart: Trusted Data Pipeline and Automated Leadership Report

Python | PostgreSQL | SQL | Open-Weights LLM

A repeatable pipeline that turns three messy grocery-delivery extracts (customers, products and orders) into one trusted set of orders, and then into a leadership report in which every figure is checked.

  • Froze and fingerprinted the raw files, loaded them as text so no value was lost, and standardised city, payment and status spellings.
  • Profiled data quality, hunted duplicates with five rules and recomputed commission, then applied seven checks that split orders into trusted and rejected-with-reason.
  • Loaded the results into PostgreSQL for analysis and a suite of 76 SQL queries.
  • Had an open-weights language model draft the report from aggregated summaries only, with a fact-checker matching every figure to a summary value.
  • Rebuilds end to end on each new Monday set of files, with 73 automatic checks that must all pass.

CloneStream Healthcare Data Crisis: Data Quality Audit, Cleaning and Reporting Platform

Python | SQL | SQLite | FastAPI | Next.js | Power BI | Databricks | GitHub Actions | Pytest

An end-to-end data-quality platform for a hospital's 20-table dataset. It measures how trustworthy the data is, finds the root causes, cleans it without losing evidence, and keeps it clean with scheduled jobs.

  • Ran 501 audit rules across bronze, silver and gold layers, with a severity-weighted score that rose from 42.2 to 66.8 after cleaning.
  • Tested 10 root-cause hypotheses with SQL evidence and statistical tests, each checked against healthy data to prove it can be refuted.
  • Cleaned with Python and SQL while logging every change and quarantining bad rows instead of deleting them.
  • Quantified the revenue gap in Finance and surfaced patient-care gaps in 13 gold tables, delivered through a Power BI report and a FastAPI + Next.js web app.
  • Automated with three scheduled Databricks jobs and a six-stage GitHub Actions pipeline.
