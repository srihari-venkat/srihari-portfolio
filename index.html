Research Project

Document Intelligence Pipeline - Autonomous Multi-Agent System for Extracting Structured Data from Arbitrary Documents

Python | FastAPI | Sarvam Document AI (Vision 1.5) | Sarvam Digitise | Groq | Pydantic | Pytest | HTML | CSS | JavaScript

Developed a multi-agent Document Intelligence Pipeline that automates document classification, information extraction and validation. The system uses Sarvam Document AI and Sarvam Digitise for OCR and document processing, Groq for intelligent extraction and reasoning and FastAPI + Pydantic for building and validating APIs. The pipeline consists of three agents: Classification Agent, Extraction Agent, and Validation Agent, enabling structured, reliable information extraction from unstructured documents.
